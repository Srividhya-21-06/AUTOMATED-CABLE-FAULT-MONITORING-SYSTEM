# AUTOMATED-CABLE-FAULT-MONITORING-SYSTEM
## 📌 Project Overview

The Automated Cable Fault Monitoring System is an IoT-based embedded project designed to detect faults in electrical cables and provide real-time monitoring using Arduino and Blynk IoT platform. The system helps in identifying cable faults automatically and sends instant alerts through the Blynk mobile application. This project improves the efficiency of fault detection in underground or long-distance cables and reduces manual inspection time.

* To detect cable faults automatically

# ⚙️ Working Principle

### Step 1 — System Initialization

The Arduino and ESP8266 connect to WiFi and Blynk server.

### Step 2 — Cable Monitoring

The system continuously checks the cable condition using sensors or fault detection circuit.

### Step 3 — Fault Detection

If any fault occurs (open/short circuit), the system identifies it.

### Step 4 — IoT Alert

The Blynk application immediately sends an alert notification to the user.

### Step 5 — Display Output

The system shows fault status in serial monitor or display module.
